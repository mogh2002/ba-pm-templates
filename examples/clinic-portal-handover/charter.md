# Project charter: Lina's handover, Sunrise Clinics booking portal

**Version:** 1.0 · **Date:** 2 March · **Owner:** Lina (BA) · **Sponsor:** Omar (delivery manager) · **Status:** approved

## 1. Goal
By Lina's last day (27 March), each of her four workstreams has a named owner who can run it without her.

## 2. Success criteria
1. Each workstream has a handover card and a walkthrough that's done.
2. Each new owner has done the main task once alone.
3. No access depends on Lina's personal accounts after 27 March.
4. Omar signs off the checklist.

## 3. Scope
**In:** requirements backlog, UAT test data, the weekly client report, the appointment-reminder change request.
**Out:** new features; the payment-gateway upgrade (owned by another team).
